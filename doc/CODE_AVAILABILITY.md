Use the following statement after the files have been uploaded and public access has been checked:

The ZLSpectra source code, validation datasets, reference outputs, and user documentation are available at https://github.com/ShaoronLiu/ZLSpectra. The software is distributed under the MIT license and runs in MATLAB. The authors tested the hematite and calcium carbonate validation cases using MATLAB 26.1 on macOS 26.6.2. Data-source attribution and reuse information accompany the datasets.
