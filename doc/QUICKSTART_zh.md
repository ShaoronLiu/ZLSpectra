# 使用说明

1. 将整个文件夹解压到本地，在 MATLAB 中打开仓库根目录。
2. 在命令窗口输入 `ZLSpectra`。
3. 选择既有矿物光谱代用指标模块，再选择 Hematite 或 Calcium carbonate。
4. 赤铁矿输入文件夹选 `data/hematite/spectra`；碳酸钙输入文件夹选 `data/calcium_carbonate/spectra`。
5. 将输出工作簿保存到单独的结果文件夹，避免与原始光谱混放。
6. 依次选择并确认特征峰谷。SG 辅助曲线仅辅助识别，振幅仍在主曲线上测量。
7. 在结果序列中点击样品可回看、修改；最后保存结果。

所有示例反射率单位为百分数，波长单位为 nm。发布包中的标准化 CSV 仍是原始反射率数据，未计算二阶导数。程序内部会按 1 nm 网格计算。

参考输出保存的是此前人工选点结果，不代表本次发布前重新运行得到的结果。赤铁矿参考输出中的数字 Sample ID 采用质量分数（乘 100 转为百分数）；标准化光谱文件名则直接标明百分含量。请按含量对应，不要仅按行号对应。
